# Bornwell Academy website

## Open in VS Code
1. Open this folder in VS Code.
3. Install the Live Server extension published by Ritwick Dey if you do not already have it.
4. Right-click index.html and choose Open with Live Server.

No npm install or build is required. This is a plain HTML, CSS and JavaScript website.

Alternative if Python is installed: open the VS Code terminal in this folder and run `python -m http.server 5500`, then open http://localhost:5500 . Stop the server with Ctrl+C.

## Files
- index.html: homepage sections and navigation
- styles.css: layout, colours, typography, animations and mobile styles
- app.js: tabs, gallery, dialogs and demo enquiry form
- assets/: supplied Bornwell Academy photos and logo; originals are preserved
- ARCHITECTURE.md: implementation and customization guide
- CODEX_NEXT_STEPS.md: your requested changes for Codex running on your own computer

The live page uses the authentic Bornwell Academy logo, supplied school photos, navy/blue/yellow branding, responsive gallery filters, a local enquiry preview and the supplied Facebook Reel integration.

The enquiry form is a local preview only. It does not send or store messages. Google Fonts use an internet connection, with system-font fallbacks available offline.
