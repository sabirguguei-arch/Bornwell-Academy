# Bornwell Academy website architecture

This is a static, responsive HTML/CSS/JavaScript site for Bornwell Academy. The visual system follows the supplied crest and school photography with navy, blue, white and yellow accents.

## Content model

- `index.html` contains the homepage, about, academics, teachers and staff, student life, achievements, gallery, Facebook Reel and enquiry areas.
- `styles.css` contains responsive layout, image grids, focus states, responsive menu behavior and reduced-motion support.
- `app.js` contains the mobile menu, enquiry preview, gallery filters/lightbox and privacy information dialog.
- `assets/` contains the original supplied photographs and logos. Original files are not renamed or overwritten.

Captions and alt text describe visible content only. The site does not identify people by name or invent staff roles, qualifications, testimonials, statistics or award claims.
